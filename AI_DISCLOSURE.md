# How I Used AI in This Project

---

### My Thoughts on Using AI

When I work on coding projects, I use AI tools pretty much the same way I use Google, official documentation, or Stack Overflow. It helps me find syntax errors faster, gives quick suggestions when I get stuck with TypeScript types, and speeds up repetitive code.

To be completely honest and transparent with the Copernicus Berlin team, here is a simple breakdown of what I used AI for, and what I created myself:

---

### 1. Where I Used  AI
* **Initial setup:** Generating the starting boilerplate files for React 18, TypeScript, and Tailwind CSS.
* **TypeScript types:** Helping me fix type errors when passing props between components.
* **CSS tweaks:** Suggesting Tailwind utility classes when I was testing responsive padding and margins for mobile screens.

---

### 2. What I Created Myself
Every single decision about what this tool is, how it works, and how it communicates with students came from my own thinking:

* **The main idea:** When I read about the International Excellence Scholarship, I saw that community engagement is its biggest differentiator. But on regular scholarship portals, this gets lost in long text. I wanted to build a friendly tool that shows students this practical side in less than a minute.
* **The 5-step user journey:** I designed the flow (Discover → Explore → Check → Learn → Apply) so students can quickly see what the scholarship offers without reading pages of formal documents.
* **The questionnaire and matching logic:** I wrote all 4 questions myself (enrollment, reasons for Berlin, team volunteering, and skills) and created the logic that points students toward tracks like Technology, Design, Media, or Research.
* **Fact-checking:** I personally checked `copernicusberlin.org/en` to make sure I did not make up any deadlines, partner universities, or funding numbers. I also added clear disclaimers on every result card so students know to always check the official website before applying.
* **Writing the content:** All the descriptions, tips, and FAQ answers were written, reviewed, and finalized by me.

---

### Summary
AI was a helpful coding assistant that saved me time on syntax and boilerplate, but all the ideas, the user experience, and the problem-solving decisions are 100% my own work.
