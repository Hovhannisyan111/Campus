# How I Used AI Tools in This Project

---

### My Approach to AI

When working on software projects today, I use modern AI tools (such as coding assistants in my editor) much like any developer uses an IDE, documentation, or Stack Overflow: to help write code faster, troubleshoot TypeScript syntax errors, and test responsive CSS layouts.

In the spirit of transparency and academic honesty requested by Copernicus Berlin, here is a clear breakdown of where digital tools helped and where the personal work came from:

---

### 1. Where Digital Tools Assisted (Technical Implementation)
* **Code scaffolding:** Setting up the initial boilerplate configuration for React 18, TypeScript, and Tailwind CSS.
* **Syntax and type debugging:** Resolving TypeScript type definitions and CSS flexbox/grid adjustments.
* **Component structure checks:** Double-checking that state changes in the questionnaire flow properly across mobile screens.

---

### 2. My Own Work, Decisions, and Ideas (Human Authorship)
Every decision regarding **what to build, why to build it, and how to communicate it** was conceived and directed by me:

* **The core idea:** Noticing that the unique aspect of IES—**Community Engagement and student contribution**—often gets lost in general exchange brochures, and deciding to build an interactive fit checker around that differentiator.
* **User journey & UX flow:** Designing the 5-step path (Discover → Explore → Check → Learn → Apply) so students can understand the programme in 60 seconds without reading a 10-page document.
* **Questionnaire & scoring logic:** Writing the 4 questions (university status, Berlin motivation, willingness to volunteer/collaborate, and skill selections) and mapping student answers to real contribution areas like IT, Graphic Design, Communications, and Research.
* **Factual integrity:** I manually reviewed the official website (`copernicusberlin.org/en`) to ensure that **no deadlines, scholarship sums, or partner universities were invented or assumed**. All result screens explicitly advise students to verify official guidelines on the portal.
* **Campaign concept:** Developing the marketing theme *“Don't Just Study Abroad. Co-Create.”* to shift student perception from passive exchange tourists to active team contributors.

---

### Summary
I believe that using AI as a coding accelerator is a valuable modern skill, but it should never replace critical thinking, originality, and genuine understanding of the audience. This submission reflects my own ideas, design choices, and problem-solving approach.
